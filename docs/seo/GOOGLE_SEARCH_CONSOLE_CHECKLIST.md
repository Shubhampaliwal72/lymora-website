# Google Search Console: owner checklist

Domain ownership is already verified according to the owner. No account access, submission or private report inspection was performed by this implementation. Never put credentials, verification tokens or private exports in the repository.

1. Select the existing lymora.in domain property. The sitemap is already fixed; do not recreate it.
2. After deploying an approved build, open Sitemaps, submit https://lymora.in/sitemap.xml if not already submitted, and check for Success. Confirm seven intended public URLs in the live XML.
3. Use URL Inspection for https://lymora.in/, /products/lan-messenger/ and /downloads/. Check Google's selected canonical and the page's declared canonical. Run Test live URL to inspect current accessibility. Request indexing when eligible; a request is not a guarantee.
4. Review Pages indexing reasons. Export the specific affected URLs and reason before deciding on a fix. A noindex release-notes handoff is intentional; it should not be forced into the index.
5. Review Core Web Vitals, Security issues and Manual actions. A lack of field data is different from a passing result.
6. In Search results Performance, record clicks, impressions, CTR and average position by query and page. Separate brand from non-brand queries. Note country/device filters and exact dates.
7. Compare 28-day periods and three-month trends when enough data exists. Do not judge a new site from a few days or repeatedly request indexing as a ranking tactic.
8. Use Google Trends to compare topic direction, not as an invented search-volume metric. Use actual Search Console queries to refine the keyword map.
9. Update seo-measurement.md monthly with date, filters, source and owner observations. Keep private screenshots/exports outside the public repository; reference a private location without secrets.

No indexing, ranking, rich-result or traffic outcome is guaranteed. Google controls crawling and search appearance. Do not buy links, invent reviews or add meta keywords.
