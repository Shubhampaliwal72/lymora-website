Before publication: owner reviews factual claims and screenshots; approve the intended route; avoid duplication with existing guide sections; check canonical/H1/internal links; update sitemap only if a genuinely new indexable route is approved; run export and browser checks. Re-review after releases that change networking, trust, support or platform compatibility. Do not publish new security features merely because unreleased desktop code contains them.

Legitimate discovery: keep the official GitHub release description, supported OS, version and website link consistent; share useful technical write-ups in relevant communities under their rules. No bought links, fake testimonials, directory spam or invented adoption numbers. Support channels remain unpublished until verified.
